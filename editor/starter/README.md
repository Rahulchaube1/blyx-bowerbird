# Bowerbird starter

Decide whether a proposed numeric-core dependency upgrade fits a declared version range.

Open the extracted folder in VS Code. With Blyx 0.2.1 and its host toolchain installed, choose **Terminal → Run Task → Run Bowerbird** or run the following command in this directory.

```sh
blyxc native-run main.blyx
```

Expected output

```text
1
1
1
1
```

The vendor directory contains the framework source for 0.1.0 and its license texts. [Read the API guide](https://www.blyx-lang.space/packages/bowerbird) · [View the release](https://github.com/Rahulchaube1/blyx-bowerbird/releases/tag/v0.1.0)
